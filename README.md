
# Week 1 Database Assignment

## Project Title
School Management System

## Description
This project creates a MySQL database for managing school student information.

## Database Name
school_management

## SQL Commands Used
- CREATE DATABASE: Creates the database.
- USE: Selects the database.
- CREATE TABLE: Creates the students table.
- SHOW TABLES: Displays the tables in the database.
- DESCRIBE: Displays the structure of the students table.

## Students Table
The students table contains:
- student_id
- first_name
- last_name
- age
- class_name
